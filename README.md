# Loan Approval Prediction Using Machine Learning

Project Overview

This project focuses on predicting whether a loan application will be approved or rejected using Machine Learning classification algorithms.

The project uses applicant information such as income, education, marital status, credit history, and other relevant features to predict loan approval status.

Objectives

- Understand and analyze loan application data.
- Perform data cleaning and preprocessing.
- Explore data using Exploratory Data Analysis (EDA).
- Build and evaluate multiple Machine Learning classification models.
- Compare model performance and identify the best-performing models.

Dataset

The project uses the Loan Prediction dataset ("loan_data_set.csv").

- Number of records: 614
- Target variable: "Loan_Status"
- Prediction classes: Y (Approved) and N (Rejected)

Model Performance

Model| Accuracy

Best Performing Models

Logistic Regression and K-Nearest Neighbors (KNN) achieved the highest accuracy of 86.18%.

Both models performed equally well based on accuracy on the test dataset.

Conclusion

This project demonstrates how Machine Learning classification algorithms can be used to predict loan approval status.

After comparing seven different algorithms, Logistic Regression and KNN achieved the highest test accuracy of 86.18%.
